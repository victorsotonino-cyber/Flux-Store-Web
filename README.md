# FLUX STORE — tienda digital

Tienda con la estructura de navegación, catálogo con imágenes, soporte, preguntas frecuentes y panel de administración de la plantilla de referencia autorizada, adaptada a la marca FLUX STORE y tema morado.

## Catálogo
YouTube Premium, Netflix Premium, Spotify Premium, HBO Max, Disney+, Minecraft Premium Java & Bedrock, Discord Nitro Basic, Nitro Procode, Nitro de 3 meses, Discord Server Boost (selector 2–24), Robux (selector 100–10.000), promoción legítima de servidor y producto oculto de cuentas antiguas marcado como no disponible.

## Panel secreto
Usa el pequeño icono de engranaje de la página Inicio. La primera vez debes crear una clave de al menos 8 caracteres en tu navegador. En el panel puedes crear, editar y ocultar productos, cambiar imágenes, precios, stock, preguntas frecuentes, moneda y enlace de Discord.
La clave se guarda en ese navegador, no en el servidor. Esta web estática no proporciona autenticación segura de servidor; no uses aquí contraseñas de otros servicios.

## Publicar cambios del panel
Pulsa Publicar cambios (datos.json), descarga el archivo y reemplaza el archivo datos.json en la raíz del repositorio. Luego haz commit. La web leerá la configuración pública actualizada cuando GitHub Pages publique el archivo.

## Precios de los selectores
En Discord Server Boost, el precio del producto equivale a un booster. En Robux, el precio equivale a cada bloque de 100 Robux. Los precios inicialmente están en blanco para que puedas fijar tus tarifas.

## Pedidos
Los botones llevan a https://discord.gg/fluxstore y copian el resumen del pedido. No procesa pagos directamente ni crea el ticket automáticamente: el cliente debe abrir un ticket en Discord.
